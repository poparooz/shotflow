# 镜序 Shotflow · 短剧分镜工作台

将现成剧本整理为文字分镜、角色与空间设定、生图和视频提示词。纯静态网页，可使用 GitHub Pages 发布。

## 功能

- Word `.docx`、TXT / MD 剧本导入与文字预览。
- 集 → 场景 → 镜头三级管理、拖动排序、每集片头。
- 角色库、中英文外观、参考主人、定妆照与角色代表色。
- 现实世界、虚拟空间及自定义光线预设。
- 画面瞬间、多人站位、焦段与景深；自然语句生图正文，独立负面提示词。
- 独立视频提示词，包含动作起止、表情、运镜和时长。
- 四阶段状态跟踪、JSON / CSV 导入导出和本场提示词复制。

## 开始使用

1. 在项目设置里填写画幅、画风与排除元素。
2. 建立角色库，上传参考图。
3. 导入或粘贴剧本，拆分为分镜。
4. 编辑画面瞬间、角色位置与镜头参数。
5. 复制提示词到生图、视频生成工具继续制作。

工作台不直接调用语言模型或生成图片、视频。AI 精修采用复制指令到 AI 对话工具，再粘贴 JSON 结果的方式，仅回填画面瞬间。

## 在 GitHub Pages 发布

将这些文件放在仓库 `main` 分支根目录。在仓库 Settings → Pages 中选择 Deploy from a branch，分支选择 `main`，目录选择 `/ (root)`，保存并等待发布完成。

资源均使用相对路径，支持 `https://用户名.github.io/仓库名/` 形式的网址，无需构建或 API 密钥。

## 本地预览

在本目录启动静态 HTTP 服务，例如 `python3 -m http.server 8000`，然后访问 `http://localhost:8000/`。网页使用 ES 模块，建议通过 HTTP 服务预览。

## 数据与迁移

剧本、分镜、角色图片和设定保存在当前浏览器的 localStorage。不同用户、浏览器和网址之间不会自动同步。更换网址前，请在旧工作台导出完整 JSON 项目备份，再到新网址恢复导入。浏览器存储已满时，应立即导出备份。

Word 文件在浏览器本地读取；旧版 `.doc` 需先另存为 `.docx`，扫描图片需先进行文字识别。
